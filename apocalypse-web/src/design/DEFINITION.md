# Apocalypse Web 设计定义

> 当前界面的视觉与交互说明。tokens.css 提供 CSS 变量，MOTION.md 描述动效执行，自动化测试检查相应行为。
> 当前界面采用苹果应用式设计语言，本文件替代旧像素表面定义；角色模型沿用 Milk Cloud 实现。

## 1. 设计方向

面向年轻企业团队的工具型管理台：macOS / iPadOS 应用式层次、精细控件、中性内容层、mint 强调、轻量导航材质和柔软品牌角色。系统字体、清楚的字级与留白形成秩序，反馈鲜明、轻快、及时可读。

Apple Liquid Glass 在本项目是 Web 视觉借鉴。仅导航、工具栏等必要功能层适度透明；表格、表单和审计信息使用稳定内容底色。实现采用已有 CSS / Tailwind / Motion，不新增依赖或运行时 AI。

### 两种完整的桌面工作方式

列表式工作区面向习惯字段对照、筛选与行操作的用户；图形化工作区面向通过对象、关系和状态变化理解业务的用户。两者共享业务契约、权限、数据与输入约束，各自完成完整任务；视图切换不能成为获得写操作的必要步骤。当前以角色管理落实该约定，不把所有业务机械转换为关系图。

图形化工作区把对象放在稳定位置，新增对象产生节点，属性变更保持对象连续，关系草稿显示待增删连线，提交成功后成为已保存状态。空间变化解释业务结果；不会以装饰动画代替保存反馈，也不在动画结束前锁住业务。表单承担属性输入，图中对象与关系承担选择和上下文操作。两种语言保留相同的失败、未保存、冲突、权限受限与确认语义。

## 2. 色彩与材质

- 正式品牌固定 mint，--brand / --primary 只负责品牌填充；--brand-foreground 负责其上文字。--brand-text 是同品牌的可读文字/焦点强调，不能把浅 mint 当小字。
- 新增 success / warning / info 及对应 foreground，危险继续 destructive；状态必须同时有文字，不仅靠颜色。归档/撤回属于中性或业务定义的次级状态。
- 所有语义颜色明暗双写。正常小字与背景对比至少 4.5:1；适用的大字至少 3:1；透明层按实际合成背景检查。
- --surface-navigation 是实色基础，--surface-navigation-glass 是可增强的导航材质；--border-subtle、--shadow-surface、--shadow-floating 分别表达弱分隔、内容层和浮层。
- navigation-surface 类先实色，在支持 backdrop-filter 时逐步增强；减少透明度或不支持时回到实色。内容与焦点的可读性不能依赖模糊。
- 组件统一使用 token / Tailwind 语义类，禁止任意颜色/间距字面量。角色 --slime-* 独立同源，保持当前已交付值，不随 accent 实验换色。

## 3. 字体、密度、圆角

- 根字号 16px；系统无衬线栈保持，主要正文 text-sm（14px）或 text-base（16px），辅助 text-xs（12px），页标题 text-2xl。数字可用 tabular-nums，技术追溯才等宽。
- comfortable 的 --spacing 为 .25rem，compact 为 .21875rem；两档根字号相同。间距和控件高度通过现有 spacing 缩放，不用压缩正文换密度。
- 控件基础圆角 --radius-control = .625rem，内容/浮层 --radius-panel = 1rem；品牌反馈可用柔和圆角，不再强制零圆角或像素阶梯边。
- 标准控件舒适高度 h-9；紧凑继续随 spacing 调节。触屏常用目标优先不小于 44px，图标尺寸与点击面积分离。关闭入口具有完整命中区域。
- 同一页面使用一致的水平留白；桌面通常 p-6，窄屏 p-4。内容页保持 min-w-0，宽表滚动限制在自身容器。

## 4. 页面层级

- 单一页面标题 → 搜索/上下文与操作 → 主工作区 → 按需详情。主操作每区一个；危险动作单独确认。
- 标准列表保留 DynaLayer schema-first。表格、搜索和表单的行为与权限一致；移动端保留对象卡片。树形和组合任务允许现有逃逸实现。
- 短编辑/确认用 Dialog，长详情用 Sheet；现有工作台可保留有名称的主辅区。都有标题、关闭、滚动正文、焦点返回；不在列表底部追加详情。
- 字段标签常驻；枚举翻译为业务用语，后端错误和业务原文原样显示。使用已有 FieldSelect / DatePicker。
- 工作台只展示已有数据支持的事实；入口以受控 component/路由/权限识别，不能依靠中文菜单标题。
- 侧栏静态 BrandSignature、多页签、工作台固定页签与关闭路由规则保留。主导航首次收起、深链按需展开，叶菜单精确高亮。
- 登录压缩窄屏品牌占高，保证输入/提交可达。保持密码闭眼、主题/语言及认证生命周期；未经探测的在线标记不展示。

## 5. 状态与可访问性

- loading、success-data、success-empty、筛选无结果、首次错误、刷新错误、权限不可用分别表达。
- 首次错误不能渲染伪零值或“暂无数据”；同一授权上下文刷新失败可保留旧数据并提示。403/404、撤权、登出/换号继续按原生命周期清理内容和迟到副作用。
- 图标操作有业务名称；焦点、hover、选中彼此区分。关闭返回触发器；200% 缩放、320px 窄宽和中文/英文仍能完成核心任务。
- 核心共享组件不能反向依赖业务模块。纯展示复用不另建数据缓存、权限真源或新的页面 DSL。

## 6. 动效与品牌

- Dialog / AlertDialog 全层 220ms 进入、160ms 退出；Sheet 280ms 进入、180ms 退出。标题、正文、操作同时出现；不再使用 PixelDialogMotion 像素裁切、分段 delay 或遮住真实内容的揭示。
- CSS 优先；Motion 仍用于已有组件/布局动画。所有 JS 数值从 design/motion.ts 读取，CSS 从同源 token 读取。
- PixelScale 保留调用接口，表现改为圆润、连续的等待节奏；PixelBubble 保留兼容组件并采用柔和气泡。命名兼容不代表保留像素外观。
- prefers-reduced-motion 与 html[data-motion='off'] 都生效；禁用后内容立即可读、可操作。任何逻辑不得依赖动画结束才允许操作。
- 数据表格和树节点不常驻装饰动画。PixelWave 仅保留开发实验室默认关闭预览，登录不挂载。
- 角色使用当前 Milk Cloud 运行实现，静态签名与角色职责分离。PixelOrb 兼容入口和 idle/waiting/success/error/sleeping 状态、384/256/128/64/32 容器、WebGPU 单后端、静态降级、隐藏暂停与资源释放保留。角色造型的人工接受以独立角色交付记录为准。
- 静态品牌图形标采用 Apo / Milk Cloud 的不对称轮廓、豆眼与微笑，与 README 首图同源；侧栏、移动导航、登录页首与 favicon 共用此图形。应用内明暗版本跟随 `.dark`，favicon 适配浏览器的系统主题。字标采用 Apocalypse 的自然大小写与系统字体。
- 工作台欢迎区使用 README 同源品牌首图，提供桌面/手机和明暗版本；常用任务、活动与会话保留现有权限和真实数据行为。首图作为静态品牌展示，不挂载 WebGPU；登录页继续保留交互角色与密码闭眼。

## 7. 验证与维护

### 2026-10-18 · 工作台与权限图谱样板

用户已选择视频参考中的柔和卡片、精密仪表与空间关系导航，并授权使用现有 Motion 制作两个可交互样板。样板限开发态独立预览入口，使用明确标注的本地示例数据；不作为真实统计或授权结果，不接入生产菜单和 API。

- 保留 mint 品牌、系统字体、既有语义颜色与明暗主题。主卡通过面积、局部品牌光晕与大数字建立重点，辅助卡维持中性表面；布局采用主卡加辅助卡，不把所有信息等权排列。
- 卡片、分段控件和图谱节点各有形状职责。样板允许专属较大卡片圆角与软阴影，数值集中在 tokens.css 的样板 token 中，不能改变其他页面的基础 token。
- 图表与图谱是数据驱动的 SVG/HTML 内容，复用 Lucide 图标和现有 Apo 签名。图谱用可聚焦按钮提供节点操作，选择节点后同步连线、关联摘要与详情；窄屏保留可操作的等价列表。
- Motion 负责数值/布局连续过渡、节点展开与轻微弹性。参数集中在 design/motion.ts 的 studyMotion；只在主动操作或首次进入时运动，无常驻粒子或循环扫描。动画关闭及 reduced-motion 下直接到达最终状态。
- 开发预览提供工作台/图谱切换、明暗、动画和中英文控制。工作台支持时间范围切换和查看关联活动；图谱支持角色选择、节点展开、权限搜索与重置。内容始终可读可操作。
- 此次是设计语言样板验收，尚未授权全站迁移或真实权限查询扩展。验收记录与截图归独立 Vault。

### 2026-10-18 · 已批准接入真实工作台与角色页

- 用户接受上述方向并授权接入两处真实页面。工作台采用主趋势卡、辅助指标与审计概览；以现有日志分页/在线会话接口为事实源。时间段样板切换替换为明确的最近50/100/200条记录样本；标明实际记录范围，保留总量不冒充周期总量，移除无接口依据的增长率/活跃人数。
- 桌面角色管理提供列表与图谱两套完整交互语言：列表延续DynaLayer，图谱通过对象节点、关系构建、上下文编辑和状态过渡完成CRUD。图谱是同一角色管理的另一种操作方式，不是只读统计页；新增/编辑/删除及授权变更均可在图谱上下文完成，不能强迫用户回列表操作。角色→目录/菜单→权限标识来自管理树与角色授权ID，显示配置关系而非宣称用户当前有效权限；关闭模块的管理节点不能被误判为运行态已开放。
- 用户进一步明确本轮只改桌面端。沿用现有md移动导航边界，窄于768px保留原有工作台与角色列表，不挂载新增图谱、统计卡片与对应动效；不以新的窄屏适配替换现有移动体验。窗口跨越边界时卸载离开的展示与查询上下文。
- 正式表面复用独立的 insights 卡片、语义token和现有Motion域。业务数据与中英文词条留在各模块；不得从_dev导入样本、固定日期或虚构身份。
- 原权限、刷新、空态、失败、403/404与身份切换语义保持。图谱编辑使用完整基线与有界草稿，新增/移除关系可见，审阅后明确保存；菜单层级与角色授权关系区分，移除关联不等于删除菜单定义。较大分支局部展开并提供完整列表/搜索；减少动态及动画关闭立即停止过渡并保留当前选择，业务行为不依赖动画结束。

样板与迁移页都需要真实浏览器证据：明暗、两种密度、窄屏、zh/en、键盘、数据状态和浮层；不得用截图代替交互测试。布局底座具有全站影响，必须覆盖所有已安装页面。

pnpm check 运行格式、lint、测试与构建。状态、授权和焦点测试验证实际行为；纯圆角与类名不建立重复快照。界面变化应同步更新相关使用说明和行为测试。

### 2026-10-18 · 参考视频适配（已授权全量交付）

用户批准对照方案（Vault `Designs/20261018-frontend-video-comparison-and-design.md`）及全部推荐决定。以下表面纳入正式设计语言；所有数值由 `motion.ts` 的 `stateMotion` 与 `tokens.css` 同源提供：

- **状态形变**：登录提交按钮收拢为等待圆，成功勾只在认证被接受后出现，失败立即复原；同一按钮元素保持焦点。
- **逐位数字**：计数类指标可使用 `AnimatedNumber variant="odometer"`，逐列滚动、位数变化平滑、快速切换可打断；默认仍为数值补间。
- **首次入场**：洞察卡片每个会话、每个授权代次只弹入一次；返回页面直接终态，刷新只变数值。
- **权限全景与组织图**：首次进入一次性生长（总时长 ≤700ms）；悬停/聚焦弱化无关分支；选择以一次性路径脉冲表达祖先或授权链。数据表面不常驻流光。路径色 `--insight-path` 明暗双写。
- **热力图**：5 级色阶 `--heat-0…4`，0 级是“记录为零”；未覆盖时段用中性斜纹，失败集中用警示斜纹，均附图例与数值读数。
- **来源幽灵层**：详情 Sheet 可从来源行“长出”——幽灵层从行矩形移向 Sheet，真实 Sheet 照常整体进入且标题、正文、操作首帧可见；来源不可见时省略。
- **卡片原地展开**：字典卡片册中展开卡片占整行，邻卡以布局弹簧让位；一次只展开一张。
- **草稿条**：多项未保存修改显示改动点、删除线原值与逐项撤销；底部草稿条提供差异、放弃与保存。草稿离页保留于内存、换号或授权快照变化即清除。
- **命令面板**：最近访问、显式外观动作、键盘脚注、随结果收缩的高度；`?` 进入确定性“规则查询 · 非 AI”授权问答。遮罩模糊仅为渐进增强，可读性不依赖模糊。

桌面增强、移动保留可操作列表的边界不变；参数工作区是唯一同时用于移动端的新编辑形态。所有新表面明暗双写、zh/en 同步、双动效开关下首帧即终态。
