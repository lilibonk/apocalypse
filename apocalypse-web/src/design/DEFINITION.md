# Apocalypse Web 设计定义

> 全站视觉的唯一事实来源。`tokens.css` 是本文件的 CSS 投影，`AGENTS.md` 是执法条款。  
> 视觉 PR 必须能指出本文件中的对应条目；对不上就先改定义，再改代码。

生效日期：2026-08-28。产品定位是可复用的通用 Web 管理脚手架，不是服务监控或可观测性产品。正式品牌签名（静态图形标 + APOCALYPSE 字标）、favicon 与 PixelOrb 吉祥物严格分离：静态签名用于登录页首、侧栏和产品署名；吉祥物只作为“值守向导”出现在登录、加载、空态、成功与异常反馈。品牌主色在正式产品中固定为 mint，皮肤 / accent 等实验能力仅在开发态“外观实验室”出现。像素语言 PixelWave 只覆盖登录品牌舞台、全局加载、进度与一次性反馈，禁止穿过表单、表格、权限树或审计信息。PixelBean / PixelTide / RetroGrid 已弃用，转向规格见 `docs/pixel-wave-spec.md`。

## 0. 分层（先读这一节）

两套语言并存，禁止混用。

| 层           | 用在哪                                                               | 气质                                |
| ------------ | -------------------------------------------------------------------- | ----------------------------------- |
| **数据表面** | 表格单元格、表单控件、对话框、命令面板、设置项（吉祥物预览除外）     | shadcn/new-york，可读、密、圆角保留 |
| **品牌表面** | 登录舞台、全局 PageLoading、空状态、不确定进度、操作成功的一次性反馈 | 像素、整数格、锐利、克制            |

正式图形标 / 字标属于静态产品签名，不是 PixelOrb 挂载点。侧栏与 favicon 禁止使用吉祥物。

不要把管理台做成 8-bit 皮肤，也不要在品牌表面继续用扫光圆角 skeleton。

## 1. 网格与锐利度

- [ ] 基础格子 **4px**。密度缩放（`--spacing`）之后，品牌表面的位移/尺寸仍落在整数格上。
- [ ] 吉祥物只允许合法阶梯 size（`256 / 128 / 64 / 32`，32 为图标态）。非法 size：**开发环境 throw**，生产打 error 并吸附最近合法值。
- [x] 品牌母版 **1254×1254**；运行时按显示阶梯建立 **2× 内部 Canvas**（512/256/128/64），身体预缩放到离屏帧并缓存，逐帧只重绘瞳孔。登录桌面 256、登录移动 / 空态 128、侧栏 / 设置预览 64、消息图标 32。
- [x] 运动参数可以是连续量（呼吸、倾斜、视线、像素块流场）；**写进 canvas 的那一帧必须是整数格**。禁止整图亚像素缩放造成发糊。
- [x] 吉祥物容器 `image-rendering: pixelated`。`body` 的 `antialiased` 只作用于正文，不作用到品牌位图。

当前合法 size：`256 / 128 / 64 / 32`。  
常用阶梯：登录桌面主视觉 256、登录移动 / 宽松空态 128、紧凑空态 / 开发预览 64、消息 / Toast 图标 32。侧栏使用静态品牌标，不占用吉祥物尺寸阶梯。

## 2. 颜色

- [ ] 正式产品品牌主色固定为 mint，写入 `--brand` / `--primary` / `--ring`；成功 / 警告 / 危险使用独立语义色，禁止跟随品牌色变化。
- [ ] 开发态“外观实验室”允许验证皮肤与 accent 联动：
  - v4 长春花蓝 ↔ accent `periwinkle`
  - v3 薄荷青 ↔ accent `mint`
- [ ] 切皮肤必切 accent；切 `mint` / `periwinkle` 必切对应皮肤。其它 accent（violet/blue/…）只改数据表面强调色，**不改皮肤**。
- [ ] 默认：皮肤 v3 + accent `mint`，对应像素蝾螈薄荷主色。生产用户设置不暴露 accent / 皮肤切换。
- [ ] 中性灰阶继续走 shadcn 语义 token（`--background` / `--foreground` / `--muted-foreground` / `--border`…）。
- [ ] 皮肤调色板（高光 / 亮部 / 暗部 / 描边 / 眼色）只活在 `effects/PixelOrb/skins/*.ts`，不进全局 token。
- [ ] 暗色一等公民：任何 `--brand` 预设必须明暗双写。

  `idle | waiting | success | error | sleeping`

- [ ] `thinking` 仅 2 期 Agent 化身使用，当前不实现，不得挪用；`loading` 语义并入 `waiting`。
- [x] 形状源：`public/brand/packet-axolotl-base/master/blink.png`；母版保留透明边缘，禁止运行时裁切状态表或换整张身体方向帧。
- [ ] 皮肤调色板只影响运行时瞳孔与品牌 accent；身体保持已确认的薄荷 / 珊瑚 / 奶油 / 深青品牌配色。
- [ ] 降级（`prefers-reduced-motion` 或 `html[data-motion=off]`）：直接显示居中视线静态母版，零监听、零 rAF。
- [ ] 氛围层唯一语言：`src/effects/PixelWave/`（v2.11 连续铅字浪潮：**基态 = 干净白/黑背景**。登录 `appearance="letterpress"` 使用 32px 固定节距（28px 顶面 + 4px 缝隙）的完整网格；每 7s 从不与上一波重复的随机角点发射欧氏距离波前，2.4s 扫过全场，0.09s 快速抬升后按 0.38s 时间常数指数回落。波包阈值以上的格子全部参与。**每波换一张噪声图**：随机 session seed 与波序号派生当波 seed，同时驱动低频距离扭曲、≤0.045s 点火抖动、浮雕高度与空间连续色带；同一波稳定，相邻波与重复进入均为新形状。铅字顶面严格绘制为 `--background`（亮色白底白块、暗色黑底黑块），抬升侧壁以 `--border` 与低透明 `--foreground` 灰阶叠加表达深度，程序化 oklch 彩色流光只画剪影边缘，禁止染色顶面。PixelWave 只允许登录舞台、全局加载、进度和一次性反馈；空表、权限树、审计列表与普通管理页禁止挂载。`PixelScale` 是同目录下的一维操作反馈形态：以 CSS `steps()` 驱动 6/12/16 根离散高度像素柱，分别用于按钮、局部与页面加载，不构成第三套品牌语言。降级时停驻为静态音阶；Canvas PixelWave 的 reduced-motion 与 P10 低帧仍为零渲染纯背景。组件恒 pointer-events-none、无鼠标或点击交互。
- [ ] `effects/PixelBean/` 与 `effects/registry/RetroGrid/` 已弃用（历史兼容保留），新代码禁止引用。

## 5. 动效

组件级实现、编排顺序与验收清单见 [`MOTION.md`](./MOTION.md)。本节定义边界，`MOTION.md` 定义执行契约。

选最弱可用工具。能 CSS 不 JS，能 motion 不 GSAP，能 GSAP 不 WebGL。

| 层  | 范围                                                        | 工具                                                         |
| --- | ----------------------------------------------------------- | ------------------------------------------------------------ |
| 0   | hover、显隐、颜色、位移                                     | CSS / Tailwind                                               |
| 1   | 页面过渡、列表 stagger、量化位移                            | `motion`                                                     |
| 2   | 吉祥物状态、像素格编排                                      | `effects/PixelOrb`、`effects/PixelWave`、`effects/` 下品牌件 |
| 禁  | 数据表正文装饰动效、亚像素弹簧、落地页流体光标、Lottie/Rive | —                                                            |

白名单场景：页面过渡、列表 stagger、命令面板/抽屉进出、品牌表面（登录/空态/加载/进度/成功反馈）、PixelOrb / PixelWave。

通用管理台只使用一组短促节拍，事实来源为 `tokens.css`，`design/motion.ts` 是 motion 的秒值投影：

| 语义               |          时长 | 用途                             |
| ------------------ | ------------: | -------------------------------- |
| feedback / exit    |         120ms | hover、press、折叠退出、遮罩退出 |
| enter              |         160ms | Dialog / AlertDialog 与遮罩进入  |
| standard           |         180ms | 页面进入、真实信息层级展开       |
| panel exit / enter | 160ms / 220ms | Sheet / Drawer 退出与进入        |

进入统一用 `cubic-bezier(0.16, 1, 0.3, 1)`，退出统一用 `cubic-bezier(0.4, 0, 1, 1)`；弹窗仅做 98% → 100% 的克制缩放。普通数据卡片不伪装成折叠卡片，只允许 hover / press 反馈；卡片展开只用于确有信息层级的 disclosure 区域。

Rive / Lottie 仍禁：二进制资产无法按「帧即数据」用代码迭代。解禁属宪法 §10，须另案。

## 9. 品牌签名与吉祥物分工

旧方案把正圆球体、圆眼与正式 logo 混为同一形象，既同质化又让管理台每个页面都像品牌展示页。当前方案拆成两套职责明确的资产：

- **正式签名**：断裂方框 + mint 信号芯的静态图形标，配 APOCALYPSE 字标。用于 favicon、侧栏、登录页首与产品署名，不眨眼、不跟随鼠标。
- **吉祥物**：高分辨率像素蝾螈只承担登录、空态、加载与结果反馈；身体母版稳定，登录低压力场景允许瞳孔跟随鼠标。
- **管理正文禁入**：工作台能力入口、权限树、表格、日志与设置正文不常驻吉祥物，也不把状态审计包装成品牌图。
- **登录锁定**：桌面端只保留一个 256px 主视觉；右侧安全访问表单为独立实色数据表面，避免 PixelWave 干扰输入。

## 10. v2.9 登录铅字浮雕决策

- **顶面同色**：登录舞台的 PixelWave 不再用半透明彩色填充覆盖块面。顶面只用 `--background`，因此亮色模式是白底白色铅字块，暗色模式是黑底黑色铅字块。
- **深度分层**：点火窗内以快速抬升、缓慢回落的离散高度驱动几何位移；侧壁只用 `--border` / `--muted-foreground` 的灰阶阶梯，彩色只允许出现在 2px 剪影线芯与极淡外沿。
- **隔离表单**：桌面 PixelWave 只铺品牌舞台，不铺安全访问表单；移动端只铺紧凑品牌头。表单维持纯数据表面，避免流光穿过输入与按钮。
- **兼容现有挂载点**：`appearance="letterpress"` 为登录专用渲染器；PageLoading 与空状态默认 `flowlight` 不变，不另起第三套动效引擎。

## 11. v2.10 图 3 忠实度纠偏

图 1/2 暴露出 v2.9 的模型错误：`35%` 参与率、0.5s 硬点火和对角走廊只产生少量空心框，无法形成研究演示图 3 的连续铅字浪潮。本节推翻登录 `letterpress` 的场模型，但保留同底色顶面与主题材质。

- **完整网格，不做随机抽样**：波包阈值以上的格子 100% 参与，连续波峰轮廓必须可读。
- **欧氏波前，不是方形环**：每波从随机角点向全场径向扩散；相邻波不得复用角点。
- **长尾高度场**：使用 `bump = (1 - exp(-u/0.09)) × exp(-u/0.38)`，让波峰之后仍保留大面积不同高度的柱体；低于 0.03 才归零。
- **固定铅字规格**：登录 fill 模式使用 32px 节距、28px 顶面、4px 缝隙，不再按 48 列等分成细小方框；最大挤出约为顶面边长的 1.45 倍。
- **布局边界**：浪潮可充满品牌舞台，但右侧登录表单仍以实色表面隔离；文字信息块可用同底色遮挡层保证可读性。
