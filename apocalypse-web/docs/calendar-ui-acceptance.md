2026-09-03；范围：前端交互、文案、共享控件和设计规范。用户批准前端 AGENTS 更新；不改接口、依赖或数据库结构。UI 实现阶段未提交或推送；后续 Git 交付授权见本文末尾。

## 实现前比较

| 方案                                                             | 变更半径与成本                                                                           | 结论                                                       |
| ---------------------------------------------------------------- | ---------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| 保留原生 select/date/month/datetime-local，仅调 CSS              | 最小；无法统一操作系统弹层、主题与键盘体验                                               | 弃选                                                       |
| 复用已装 Radix Select/Popover、Button、Sheet，薄封装受控日期选择 | 共享控件一次收口；无新许可或网络依赖；须自行测试公历网格、键盘和边界                     | 采用                                                       |
| 引入新的日期组件库                                               | 成熟复杂日期能力，但增加依赖审批、主题适配、包体和升级面；目前仅单日、单月和本地时间输入 | 暂不采用；出现范围选择、多历法输入、复杂禁用规则时重新评估 |

核验依据：[Radix Select](https://www.radix-ui.com/primitives/docs/components/select)、[Radix Popover](https://www.radix-ui.com/primitives/docs/components/popover)、[React Router NavLink](https://reactrouter.com/api/components/NavLink)。本地已装 radix-ui；现有 Sheet/Dialog 负责焦点返回与品牌动效。没有拷入上游实现。日期选择只选择公历，不计算农历事实。

## 交互合同

- 初次进入工作台目录全部收起；直达深层页面只展开当前分支。叶菜单精确匹配，不把 `/calendar` 当作所有日历子页面的选中项。
- 页面分成标题说明、操作/上下文、主要工作区、按需详情。长流程用标签页分离编辑、复核、历史；不把全部表单垂直铺开。
- 月格只显示日号、简短农历日/新月月名、节日/节气。点击打开日期详情抽屉；完整比较和技术追溯按需展开；关闭返回日期按钮。
- Select 使用受控 Radix 弹层、同宽触发器、空态说明。日期/月/本地时间统一共享控件；支持月份/年份跳转、键盘、今天/清除、Escape。
- 输入输出保持 `YYYY-MM-DD`、`YYYY-MM`、无时区的 `YYYY-MM-DDTHH:mm`；不通过 UTC 转换改变业务日期。全天结束日期“不含”的契约保留。
- 中文界面不直接暴露内部枚举；角色、来源、冲突动作解释业务效果。用户内容、文件名、时区标识、来源键不误翻译；哈希放在折叠追溯区。
- 权限、ownership、版本与二次确认不因界面收敛而移除。回滚只恢复前端文件，无数据迁移。
