## 最新范围调整（覆盖下文第 4 项的浪潮挂载要求）

用户随后明确要求：像素浪潮仅保留为动效实验室的开关，默认关闭，登录页不展示。登录桌面/移动分支均移除 PixelWave，保留 gaze 与其它三项修复。复用现有开发态外观实验室、CAPABILITY_META、zustand persist 与 Switch；新增 pixelWaveEnabled=false，仅控制实验室预览，生产恒关闭。折叠实验室或关闭抽屉即卸载预览。没有新路由、依赖或通用扩展机制，Solution Fitness Gate 为 not-required（既有设置接入约定内的局部变更）。

比较：不选全局开关控制登录背景，因为与“不要在登录页展示”冲突；选择局部实验预览，以回归测试约束登录零 PixelWave、默认关闭、开启/关闭挂载与收起卸载。此前叠加浪潮性能采样仅属于实验负载，不再代表正式登录页。

## 气泡体验重新打开（用户追加反馈）

用户指出气泡漂浮失真。重新打开 softie 参考页的连续帧，参考截图 revision-02-source-bubbles.png：细小、透明、覆盖身体内部（包括五官后方），不是近表面的亮珠圈。当前代码问题可复现：金属度 0.9、半径偏大、深度集中在前表面 88%–97%，三轴正弦往返且脸部区域刻意留空。

选择有慢速浮力方向的上浮轨迹，小幅横向漂移，体积分布与非金属透明气泡；循环仅在淡出区重生。弃选继续调三轴正弦振幅，因为不能消除往返与表面附着观感。不新增粒子引擎/依赖；同一形变、生命周期和材质封装内的局部纠正，SFG not-required。上浮为根据可见参考作出的实现近似，并非声称获得示例源码；公开 bundle 在浏览器无法打开，未绕过限制。验收新增单向性、循环连续可见性、体内边界、停止动效与录屏比较。

## 人工发现与修正目标

1. 鼠标按压出现整块焦点边框：pointer 聚焦不展示键盘 focus ring，Tab/键盘操作保留可见焦点。
2. 暗色只是换背景/阴影，身体材质未切换：增加独立冷青绿暗色配方，热切主题与直接暗色打开必须一致；静态海报同样自动切换。
3. 气泡只有固定位置随身体形变：增加异步、缓慢、有边界的内部漂浮，不穿出身体；停用动效时停驻。
4. 恢复既有登录 PixelWave letterpress 背景及 gaze 鼠标跟随；保留新的软体交互、密码闭眼与所有认证行为。

## Solution Fitness Gate

类别：not-required（局部修复 / 恢复已有契约）。不新增依赖、业务模块、服务端契约或渲染引擎；复用现有 PixelWave、gaze 属性、主题 token、WebGPU/物理/生命周期封装与测试。前次本任务自行写入的“移除浪潮/固定单一材质”规定，按本轮用户明确要求同步纠正，不能作为拒绝恢复旧体验的依据。

已检查 Slime/scene/runtime/expression、PixelWave、settings 的 DEV 能力裁剪、tokens 和现有纯函数/引擎契约测试。

- 焦点：保留单纯 :focus-visible 会继续受程序化 canvas.focus 的输入模式影响；选择显式指针/键盘来源门禁，不用 blur 破坏键盘操作。
- 背景：复用原 Canvas 2D PixelWave（不是 WebGL），不复制或重写波浪算法。优先真实透明 WebGPU 画布与主题材质，避免不透明矩形遮住浪潮；不引入跨引擎截图/纹理传输耦合。
- 气泡：选择解析、有界、不同相位的内部漂浮，继续走同一软体形变；不为装饰运动引入新的粒子求解器/依赖。
- 视线：恢复现有 gaze opt-in，眼睛在皮肤坐标内有限、平滑移动，重新计算表面深度；不用屏幕空间漂浮覆盖物。
- 配色：明亮 mint / 暗色冷青绿为本轮未指定色相下的默认假设；不受 accent 或历史 skin 选择影响。材质/光照/散射 token 必须全量更新，海报按明暗分组。

重新评估条件：透明合成使亮色目标明显偏离；暗色仍发灰；全舞台浪潮+软体负载不满足 60 FPS；形变后的气泡/视线穿皮。回滚仅限本轮本任务代码，不覆盖用户既有改动。
